# Triangle Calculator

A simple console-based Java application that validates whether three given side lengths can form a triangle and allows the user to calculate its properties through an interactive menu.

## Features

- **Triangle Validation:** Checks if the provided side lengths satisfy the triangle inequality theorem.
- **Area Calculation:** Computes the area using Heron's formula.
- **Perimeter Calculation:** Calculates the total perimeter of the triangle.
- **Triangle Classification:** Identifies whether the triangle is equilateral, isosceles, or scalene.
- **Interactive Menu:** Lets you perform multiple operations or enter a new triangle without restarting the program.
